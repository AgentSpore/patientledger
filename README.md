# PatientLedger

> A personal health event store and portability layer for chronic-illness patients who have churned through six tracking apps. Local-first store, FHIR-compatible import-export, an aggregator that rebuilds a unified timeline from any past app export, and a CLI that lets patients move to a new tracker without losing history.
